What It Does

Students can register, join communities, publish posts, upload images, comment in threaded discussions, save useful threads, vote on content, respond to anonymous polls, message other users, and track campus events.

Tech Stack

Python Flask PostgreSQL SQLAlchemy Flask-Login Alembic Migrations Pytest QA Suite Gunicorn/Render Ready Bootstrap/CSS

Core Features

  • User authentication and settings
  • Communities with join/leave flows
  • Posts, comments, saves, upvotes and downvotes
  • Anonymous polls with live result percentages
  • Image uploads with validation and resizing
  • Official Glenville branding with light and dark mode

Advanced Features

  • Admin moderation queue, reports, and scoped community moderator roles
  • Pin, unpin, lock, edit, and delete tools
  • Notifications, unread dropdowns, and direct messages
  • Events calendar, Pioneer Pulse, and campus activity sidebar
  • Onboarding flow for joined communities

Database Design

The app uses relational tables for users, communities, community moderators, posts, comments, votes, saved posts, poll options, poll votes, events, direct messages, notifications, reports, and memberships.

Users Communities Posts Comments Votes Polls Messages Reports Moderators Events

Quality & Testing

  • 17 automated pytest checks for auth, posting, voting, polls, links, uploads, moderation, and security headers
  • Route smoke tests for core pages and internal links
  • Friendly error pages for common failures
  • Health check endpoint at /healthz

Security & Deployment

  • CSRF protection and safe redirects
  • Password hashing and login/register rate limiting
  • Secure cookie settings and security headers
  • Render/Gunicorn deployment setup with PostgreSQL migrations

Why This Is Impressive

This is not just a static website. It is a working full-stack web application with persistent data, real account sessions, authorization rules, interactive voting, anonymous polling, file uploads, scoped moderation workflows, deployment readiness, automated QA coverage, and a user interface tailored to a university community.
