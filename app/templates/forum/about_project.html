What It Does

Students can register, join communities, publish posts, upload images, comment in threaded discussions, save useful threads, vote on content, respond to anonymous polls, message other users, and track campus events.

Tech Stack

Python Flask PostgreSQL SQLAlchemy Flask-Login Alembic Migrations Bootstrap/CSS

Core Features

  • User authentication and settings
  • Communities with join/leave flows
  • Posts, comments, saves, upvotes and downvotes
  • Anonymous polls with live result percentages
  • Image uploads with validation and resizing

Advanced Features

  • Admin moderation queue and reports
  • Pin, unpin, lock, edit, and delete tools
  • Notifications and direct messages
  • Events calendar and campus activity sidebar
  • Onboarding flow for joined communities

Database Design

The app uses relational tables for users, communities, posts, comments, votes, saved posts, poll options, poll votes, events, direct messages, notifications, reports, and memberships.

Why This Is Impressive

This is not just a static website. It is a working full-stack web application with persistent data, real account sessions, authorization rules, interactive voting, file uploads, moderation workflows, and a user interface tailored to a university community.
